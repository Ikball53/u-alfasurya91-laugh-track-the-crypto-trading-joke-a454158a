# Laugh Track: The Crypto Trading Joke Contest

Entry: a single-line joke about crypto trading life, written by `main.py`
to `/output/entry.txt`.

## The joke

> I didn't lose money on that coin, I just promoted it to a long-term hold.

## How it works

`main.py` (Python 3.13, stdlib only) builds the line from its own code —
`build_joke()` returns the string — and writes it, plus a trailing newline,
to `/output/entry.txt`. No network, no randomness, deterministic output.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
